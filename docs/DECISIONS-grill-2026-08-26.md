# 微國家 — 需求 grill 決策紀錄(2026-08-26)

網頁版多人國家模擬經營遊戲。目的=**公開上線累積作品**。MVP 含多人互動。

## 核心決策(15 項,全數與使用者對齊)

1. **賽季制**:單世界跑 8 週後結算重開;跨賽季保留玩家檔案(名人堂/歷季名次)。
2. **每小時 1 tick**+行動點數制(每 tick 發放、可囤 1-2 天,重大操作消耗),離線友善、防腳本。
3. **抽象區域制**:8-12 個大區,國家帶 `region_id`;同區互動成本低、跨區高;前端 SVG 風格化示意圖,不做格子地圖。
4. **資源**:糧食/礦石/燃料/金錢 4 種+科技點(不可貿易)。區域產出特化逼出貿易需求。循環:人口→產出→養人口/建築/軍隊/市場。貿易走**全球市場掛單制**(系統核心,非私聊面交)。
5. **軍事**:tick 自動解算(兵力×科技×士氣+小隨機),行軍時間=f(區域距離)給防守反應窗。損失上限=未保護資源 20-30%,倉庫提供保護額度;建築只受損可修;**不可滅國**。新手 7 天保護+打農無收益。
6. **外交**:系統強制三種條約——NAP(系統擋攻擊,毀約=賠償+全服背信標記)、同盟(協防)、貿易協定(關稅減免)。信譽公開顯示。提案介面:發起→接受/拒絕/還價。
7. **政策**:4 軸卡槽制(稅率/經濟路線/兵役/開放度),每檔明確 trade-off,改動有 48 tick 冷卻+成本。事件系統=第二階段。
   > **變更註記(2026-08-26,routes/game/tick 一審 finding #17)**:本項當初口頭決策的冷卻數字是 48 tick,
   > 但 `packages/shared/src/constants.ts` 正本 `POLICY_CHANGE_COOLDOWN` 定案已是 24(多輪 grill/實作
   > 皆沿用 24,packages/** 依交辦鐵則不可回頭改動)。docs/CONTRACT.md 與 `apps/api/src/routes/policy.ts`
   > 皆以 shared 正本(24)為準,本行的「48」為歷史決策紀錄原文保留、不回填修改,以此註記標示落差,
   > 不視為 CONTRACT 變動。
8. **一國一城**:8 種左右建築升級制(農場/礦場/煉油/市場/兵營/倉庫/大學/城牆),1-2 個升級佇列位。人口=活資源:成長=f(糧食盈餘,稅率,士氣),決定產出與徵兵上限。多城=第二階段(最多 2-3 城)。
9. **帳號/反作弊**:Email+密碼免驗證即玩、驗證後解鎖貿易。反輸送:無定向轉帳只有市場掛單、價格帶 ±30% 限制、同 IP 成交標記不禁止、保護期限制大額交易。
10. **技術棧(使用者明確要求不用自有 Hetzner VM)**:Cloudflare Workers + D1(SQLite)+ Pages,月費 $0。tick=Cron Triggers 每小時觸發(serverless 天作之合)。後端 Hono+TypeScript,前端 React+Vite+Tailwind,前後端共用型別與數值公式。通知=30-60 秒輪詢(無 SSE/WS)。
11. **排行榜**:綜合國力分(經濟+軍事戰功+科技+外交履約)。軍事計**戰功非囤兵**,打強敵分多、打農趨零。4 分項榜(首富/戰神/科技/信譽)+名人堂。
12. **國旗**:組合式產生器(分割樣式×調色盤×內建徽章),存參數 JSON、SVG 渲染,結構上不可能違規。國名自由輸入+敏感詞黑名單+檢舉+管理端改名;允許重名。
13. **冷啟動**:MVP 內建 20-30 個 NPC 國家(狀態機行為,照規則不開掛),自動市場掛單給流動性、當新手練習對象(戰功打 5 折防刷榜),玩家增多後逐季調降。
14. **教學**:任務鏈「建國之路」12-15 步,每步教一系統+給獎勵;頁面常駐「?」說明角。任務鏈完成前或 7 天內不可被攻擊。
15. **語言/視覺**:繁中優先但 i18n 字串第一天就抽離;視覺=乾淨儀表板/公文擬物風,支援深色,不做遊戲美術。

## UI 方向定案(2026-08-26 /prototype 結論)

原型 `prototype/ui-variants.html` 三變體(A 公文紙張/B 數據面板/C 地圖主視覺)比對後,使用者選定 **C+B 混合**:
- **C 地圖主殼**:登入後主畫面=世界區域 SVG 地圖+國庫/內政 HUD+警報流+功能 dock;行軍路線、地緣動態畫在地圖上。
- **B 數據面板內頁**:建設/市場/政策/軍事/外交/排行等功能頁用深色數據面板版式(KPI 卡、進度條、列表)。
- **A 元素局部借用**:條約簽署等儀式性畫面用印章/公文質感點綴。
- 配色以 C 的深藍海圖色系為基調,B 內頁沿用同色階。
